# Знакомства

Модуль перенесён из `Artem@5341949` 28.09.2026 и подключён к общему MAX-приложению
по последующему решению владельца. Исходники домена и UI остаются в `dating/`.

## Общее приложение

Вход: авторизация → регистрация общего профиля → «Куда хотите зайти?» →
«Социальная сеть» или «Знакомства». Повторного аккаунта и отдельной авторизации
в знакомствах нет. Имя, возраст, пол, город, фото и описание берутся из общего
профиля. Знакомства доступны с 14 лет и включаются добровольно. Пользователи
14–17 видят и могут матчиться только друг с другом; 18+ находятся в отдельном
взрослом пуле и при первом включении подтверждают совершеннолетие. Сервер
проверяет возрастной пул и пол при каждом действии.

- Основной Go backend монтирует API на `/api/v1/dating/` с общей сессией.
- `backend/internal/dating` хранит настройки, свайпы и мэтчи в PostgreSQL.
  Миграции выполняются обычным механизмом общего backend.
- Дружба, блокировки, жалобы модераторам, медиа и realtime — общие.
- После взаимной симпатии создаётся общая дружба; переписка открывается в MAX.
- Удаление данных знакомств не удаляет общий аккаунт, блокировки и жалобы.
- Основной frontend загружает UI знакомств лениво; CSS ограничен `.dating-root`.
- Общая сборка требует каталог `dating/` рядом с `backend/` и `frontend/`.
  Отдельные dating API, бот, JSON-файл и service token для неё не нужны.

Правила: [AGENTS.md](AGENTS.md), [сервисы](../docs/SERVICES.md).
Подтверждённые проблемы исходного прототипа и границы проверки:
[аудит](../docs/ai/audits/2026-09-28-dating.md).

## Самостоятельный локальный прототип

сохранены для разработки и проверки исходного прототипа. Они не запускаются
общим приложением. FileRepository с JSON не предназначен для production общего
приложения: известные ограничения записи и сортировки описаны в аудите.
Историческая HTTP-связка прототипа не заменяет подключение к общему MAX backend.

```bash
cd dating
cp .env.example .env
docker compose up
```

Frontend: `http://localhost:5174`, API: `http://localhost:8088`.
Демонстрационные анкеты доступны только с `DEV_MODE=1`.

```bash
# Остановка:
```

Скрипт запрашивает токен локального бота, собирает preview, запускает polling и
Cloudflare Tunnel; может установить cloudflared через Homebrew. Логи и данные
в `dating/.local/` исключены из Git. Не запускайте эти инструменты для деплоя
общего MAX-приложения. `install-sync-macos.sh` относится только к ветке Artem.

## Проверки

```bash
cd frontend && npm ci && npm run build
cd ../backend && go test ./... && go vet ./...
# Из корня — самостоятельный прототип:
cd dating/frontend && npm ci && npm run build
cd ../backend && go test ./...
```

Интеграционные тесты PostgreSQL запускаются с `KUTEZH_AI_TEST_DATABASE_URL`,
ссылающимся на изолированную базу с `_ai_test_` в имени. Production для тестов
не используется.
