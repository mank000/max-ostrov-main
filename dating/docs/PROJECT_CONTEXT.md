## Принятые границы

Основной профиль Кутёжа определяет имя, возраст, пол, город, описание и фото. Раздел знакомств читает его через подтверждённую сессию основного API. Данные о цели знакомства, предпочтениях, симпатиях, мэтчах, блокировках и жалобах хранятся отдельно. Отдельной переписки у знакомств нет: после взаимной симпатии пара становится друзьями общего аккаунта, а кнопка сообщения ведёт в MAX-чат. Пользователь включает показ явно; минимальный возраст — 14 лет. Пользователи 14–17 работают только внутри подросткового пула, а 18+ — только внутри взрослого. Взрослое подтверждение запрашивается только после достижения 18 лет и не является проверкой документов.

## Визуальный язык

Dating использует официальный `@maxhub/max-ui@0.5.0` для интерактивных контролов и провайдера темы. Поверх него сохранён визуальный язык основного приложения Кутёж, а не отдельный дефолтный MAX UI showcase: шапка, навигация, spacing, карточки и токены повторяют текущий frontend Кутёжа. Нативные элементы, отсутствующие в MAX UI 0.5.0 (например select), оформляются теми же CSS-токенами Кутёжа.

Текущий UI Kit использует системный шрифт, белую/тёмную поверхности `#fff`/`#17181c`, текст `#060708`/`#fff`, акцент `#007aff`, вторичную поверхность `#f5f7fa`/`#25262d`, разделители `#e4e5e7`/`#36373d`. Шапка 56 px, основная кнопка 48 px с радиусом 12 px, поле/иконка 44 px, нижняя навигация 60 px плюс safe area, базовый боковой отступ 16 px. Иконки скопированы из текущих SVG-ресурсов Figma UI Kit. Декоративные градиенты не используются.
